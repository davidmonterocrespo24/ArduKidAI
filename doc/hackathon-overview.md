# Google Cloud Rapid Agent Hackathon - Overview

Source: https://rapid-agent.devpost.com/
Captured: 2026-05-25

## Tagline

> AI that doesn't just provide answers - it helps you take action.

Building Agents for Real-World Challenges is an opportunity to move beyond the chatbot and into the world of agents that accomplish tasks. The hackathon is designed for every level of technical builder. Participants build agents that can reason, plan, and execute tasks under user oversight, powered by Gemini's reasoning and technology partners' MCP solutions.

> You provide the logic; Gemini provides the brain; our partners provide the superpowers.

## Partner tracks (six total)

Six partner tracks; each is judged in its own "Partner Bucket" so participants only compete within the partner technology they chose.

- Arize
- Elastic
- Fivetran
- GitLab
- **MongoDB** (our track)
- Dynatrace

### How to qualify for a track

1. Pick a partner technology that fits the mission.
2. Build the agent with Gemini 3 using Google Cloud Agent Builder. Integrate the partner's MCP server to give the agent its "superpowers".
3. Compete against other builders within that same partner category.

## Example challenge themes (informational, not required)

- **2026 World Cup:** fan logistics automation, local business management for tourist surges, automated fantasy leagues.
- **Financial services:** real-time fraud detection, loan workflow automation, personalized wealth management.
- **Brick-and-mortar retail:** real-time shopper navigation, hyper-local tenant campaigns, facility operations.

Agents are also welcome to target personal workflow, hobbies, or daily routine problems. **Our submission (a kid-friendly Arduino IDE) sits in the personal/educational category and is explicitly allowed.**

## Goals the agent must hit

1. **Move Beyond Chat:** the agent should use tools to accomplish tasks, not just answer questions.
2. **Multi-Step Mission:** plan the steps and use the available tools to finish the job, while keeping the user in control.
3. **Partner Power:** demonstrate meaningful integration with at least one participating partner's solution via MCP.

## Judging criteria (equally weighted)

1. **Technological Implementation** - Quality of integration with Google Cloud and partner services; software development standards.
2. **Design** - Thoughtfulness of UX and interface.
3. **Potential Impact** - Scale of positive impact on target communities.
4. **Quality of the Idea** - Creativity and uniqueness.

Tie-break: criteria order, then judge vote.

## Judges

18 total: 6 from Google Cloud, 2 from each of the six partners.
